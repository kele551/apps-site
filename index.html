你可能在担心

这几条是单文件 exe 最常被问到的，先说清楚。

杀毒软件报毒 / SmartScreen 提示「未知发布者」怎么办？

个人开源项目没有购买代码签名证书，Windows 对未签名的 exe 会弹提示，这是常见现象。可以在「属性 → 详细信息」核对版本号；程序为 MIT 开源，源码可自行审阅与构建。建议只从本页链接或官方仓库下载，别用第三方转载包。

怎么卸载？会不会改我电脑的设置？

没有安装过程，也就没有卸载步骤：删掉那个 exe 即可。狐径运行时只写当前用户的注册表代理项，点「退出并还原」立即恢复；壁纸助手不写自启动项、不装服务和计划任务。

会不会上传我的数据？

不会。四款都是本机运行，不采集、不上传用户数据。壁纸图片、新闻标题、直播源检测结果都只存在你自己电脑上；本页本身也没有统计脚本和第三方 CDN。

支持哪些系统？需要联网吗？

Windows 10 / 11，单文件 exe，中文界面。工具本身要联网才能取数据（GitHub 连通性、壁纸、直播源、新闻），但安装和启动不需要联网下载依赖。

怎么升级？版本还维护吗？

狐径与壁纸助手的控制面板里有「检查更新」；也可以回到本页重新下载覆盖，配置与收藏保留。每张卡片都标了版本号和最近更新日期，方便你判断项目是否在维护。

页面上的下载数、浏览数是怎么算的？

下载 = GitHub Releases 各附件下载数 + GitCode 的 download_statistics；浏览 = 该仓库实际存在的每个平台（GitHub / GitCode / Gitee）访问计数之和。四款从 2026-10-27 起同一口径，由一个 Cloudflare Worker 现场算，页面经 img.shields.io 中转读取；单平台瞬时取不到时回退到上次成功值，所以数字只会稳、不会忽然腰斩。LIVE直播源在 GitCode / Gitee 没建仓，那一项按 0 计。卡片与首屏的数字每次打开现场取，取不到时保留快照。卡片里的 hiwiki 镜像加速是第三方聚合站（git.hiwiki.org）的境内直连入口，安装包仍出自上面这些仓库，它自己统计的下载量不计进这里。
