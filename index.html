数字怎么来的

下载 = GitHub Releases 各附件下载数 + GitCode 的 download_statistics； 浏览 = 该仓库实际存在的每个平台（GitHub / GitCode / Gitee）访问计数之和。 四款从 2026-10-27 起同一口径。合计由一个 Cloudflare Worker 现场算，页面通过 img.shields.io/endpoint.json 读同一份数据；单个平台瞬时取不到时回退到上次成功值， 所以数字只会稳、不会忽然腰斩。LIVE直播源在 GitCode / Gitee 没建仓，那一项按 0 计。
